# Nexora AI V3 — Animated

Animated Nexora frontend with server-side OpenAI Responses API.

## Deploy
1. Upload these files to the `nexora-ai` GitHub repo.
2. Import the repo into Vercel.
3. Add `OPENAI_API_KEY` in Vercel Environment Variables.
4. Set `OPENAI_MODEL` to a model available to your OpenAI API account.
5. Deploy.

Animations: ambient glow, sequential hero text, rotating orb, scroll reveal, card scan hover, system pulse, and AI thinking state.

The X link uses the placeholder identity `@TryNexora`.
